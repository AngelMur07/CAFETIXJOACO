CAFETIX JOACO

Consulta, pide y reclama tu pedido con turno.

Sistema web de la cafetería de la Institución Educativa José Joaquín Flórez Hernández. Permite consultar productos, realizar pedidos y obtener un turno para reclamarlos, con el fin de reducir aglomeraciones en los descansos.

Ver catálogo {% if not sesion_iniciada %} Iniciar sesión {% endif %}

Características principales

Catálogo digital

Consulta los productos disponibles y sus precios antes de pedir.

Pedidos rápidos

Arma tu pedido desde el celular o un computador, de forma clara.

Turnos organizados

Recibe un turno para reclamar tu pedido y evitar filas desordenadas.

¿Cómo funciona?

01

Consultar productos

Revisa el catálogo y los precios de la cafetería.

02

Realizar pedido

Selecciona los productos y confirma tu carrito.

03

Realizar pago

Completa el pago para registrar el pedido.

04

Obtener turno

El sistema asigna un número de atención.

05

Reclamar pedido

Acércate a la cafetería cuando llamen tu turno.

Beneficios del sistema

  • Menos aglomeraciones
  • Mayor organización
  • Pedidos más claros
  • Consulta de productos y precios
  • Atención mediante turnos
