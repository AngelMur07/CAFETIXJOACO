¿Por qué faltan los costos de algunos productos?

Para calcular la utilidad de la cafetería, no basta con conocer el precio de venta: también es necesario registrar cuánto costó comprar cada producto al proveedor.

Actualmente, hay productos con ventas registradas que todavía no tienen su costo de adquisición registrado: {% if informe_utilidad.productos_sin_costo %}{{ informe_utilidad.productos_sin_costo | join(', ') }}{% else %}Coca-Cola personal, Gatorade, Cubano y Manzana Postobón{% endif %}. Por este motivo, el sistema puede calcular los ingresos por ventas, pero no la utilidad exacta de esos productos.

¿Qué debes hacer?
  1. Consulta cuánto cuesta comprar cada producto al proveedor.
  2. Registra su costo unitario en el campo Costo de adquisición del catálogo, cuando esté habilitado.
  3. Guarda el cambio y verifica los reportes de utilidad.
{% if not informe_utilidad.tiene_columna_costo %}
Estado en la base de datos: El campo Costo de adquisición no está habilitado actualmente en la base de datos utilizada (columna Prod_Costo no presente). Por seguridad y transparencia, el formulario de productos no muestra un campo que no pueda guardar información.
{% endif %}

Importante: Registra únicamente costos reales. No uses el precio de venta como costo ni inventes valores. Mientras falte algún costo, la utilidad total puede aparecer como no disponible para evitar mostrar resultados incorrectos.
